GEOTOOLS_

Tools for Geotechnical Engineering

> ABOUT_

GeoTools entwickelt digitale Werkzeuge zur Vereinfachung wiederkehrender Arbeitsabläufe in der Geotechnik.

> TOOLS_

[01]

COPY HOTKEY

ACTIVE

Kleines Hotkey-Tool zur Beschleunigung wiederkehrender Kopier- und Eingabeprozesse.

> HOTKEY > AUTOMATION > WORKFLOW TOOL
[02]

GRAIN DATA TO EXCEL

BETA

Automatisierte Aufbereitung von Kornverteilungsdaten und Ausgabe in eine strukturierte Excel-Datei.

> GRAIN SIZE DATA > EXCEL EXPORT > AUTOMATION
[03]

SCREEN CALC

IN DEVELOPMENT

Zahlen direkt vom Bildschirm erfassen, erkennen und für Berechnungen weiterverwenden.

> SCREEN SELECTION > NUMBER RECOGNITION > QUICK CALCULATIONS > VALUE EXTRACTION
